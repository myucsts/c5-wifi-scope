C5 Wi-Fi スコープ

ESP32-C5(M5Stamp C5)を使って、学校などのWi-Fi環境を見える化するツールです。どちらもブラウザの中だけで動きます。

チャンネル占有・AP一覧2.4GHz / 5GHz のAP、チャンネルの混み具合、チャンネル幅、おすすめチャンネル Wi-Fi ヒートマップ図面(画像、または作図)の上で、点ごとに電波の強さを測って色分け。移設前後の比較もできます

使う前に

  • パソコンの Chrome または Edge で開いてください(USB接続に Web Serial を使います)。
  • ボードに firmware/c5_wifi_scope のスケッチを書き込みます。手順はリポジトリの README にあります(動作確認は M5StampC5 で行っています)。
  • 測定データや図面は、ブラウザの中だけで扱います。サーバーには送られません。
